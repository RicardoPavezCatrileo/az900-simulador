Conceptos clave del capítulo

Capas: curso vs Microsoft Learn

  • Microsoft Learn (examen): seguridad física → identidad y acceso → perímetro → red → proceso → aplicación → datos.
  • El curso (castillo): políticas y procedimientos → física → perímetro → redes → hosts → aplicaciones → datos.
  • Diferencias: el curso agrega "políticas" afuera y no tiene una capa de identidad; "hosts" = "proceso".

Endpoints

  • De servicio: la subred llega al servicio por la red de Microsoft. El endpoint público sigue existiendo, no hay acceso privado desde local y el alcance es el servicio completo.
  • Privado: una NIC con IP privada en tu VNet para un recurso concreto. Llega también desde redes conectadas por VPN o ExpressRoute y puedes desactivar el acceso público.

Azure Key Vault

  • Secretos, claves de cifrado y certificados en un lugar seguro.
  • Seguridad de hardware: ni Microsoft puede ver las claves.
  • Aislamiento: una app no accede a los secretos de otra.
  • No pongas usuario y contraseña de la base de datos en el código.

Microsoft Defender for Cloud

  • Antes Azure Security Center. Protección nativa de la nube, híbrida y multinube (AWS, Google Cloud).
  • Evaluación continua, recomendaciones, alertas, protección de VMs y cumplimiento regulatorio.
  • Ciclo: definir políticas → proteger → responder a alertas.

Microsoft Sentinel

  • Antes Azure Sentinel. SIEM: información de seguridad y gestión de eventos.
  • Recolecta → agrega y normaliza → detecta amenazas → investiga.
  • Análisis de comportamiento con IA, escala de la nube e integración con AWS.
