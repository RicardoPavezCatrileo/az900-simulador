AZ-900 · Capítulo 7 · Laboratorio

Servicio y tipo de cuenta de Storage

Dos preguntas distintas: ¿qué guardas? (el servicio: Blob, Files, Queue, Table o disco) y ¿en qué cuenta lo pones? (Standard GPv2 o una de las tres Premium). En Premium, cada cuenta admite un solo servicio y por eso se llama como él: Premium File Shares es la cuenta que solo guarda Azure Files.

Regla para el examen

block = objetos · page = discos · file = compartidos. Si dice NFS → Premium File Shares. Si pide varios servicios, menor costo, GRS/GZRS o niveles Hot/Cool/Archive → Standard GPv2. Si pide el tipo de disco más rápido → Ultra (disco administrado, no una cuenta). Que NFS exija Premium y los nombres internos (kind) no están en el PDF; sí en Microsoft Learn.
