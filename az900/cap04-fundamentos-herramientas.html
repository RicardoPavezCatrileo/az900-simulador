Fundamentos de herramientas: cómo administrar Azure

Hay varias formas de crear y administrar recursos: con clics, con comandos, con archivos o desde el teléfono. Compara cómo se hace la misma tarea en cada herramienta y juega con el panel de Azure Advisor.

2 · Panel de Azure Advisor

Marca los problemas que tienen tus recursos. Advisor analiza la configuración y la telemetría de uso, y te da recomendaciones en 5 categorías. Los puntajes son ilustrativos.

    Conceptos clave del capítulo

    Azure Portal

    • Consola web unificada y gráfica (portal.azure.com).
    • Presencia en cada centro de datos de Azure: resiste fallas individuales y queda cerca de los usuarios.
    • Se actualiza sin tiempo de inactividad.

    Azure CLI

    • Línea de comandos multiplataforma (Windows, macOS, Linux), pensada al estilo Bash.
    • Comandos az … con sintaxis simple.
    • Permite scripts para automatizar tareas.

    Azure PowerShell

    • Módulo de PowerShell con cmdlets Verbo-Sustantivo (New-AzVM, Get-AzResourceGroup).
    • PowerShell viene en Windows y también funciona en Linux y macOS.
    • Se integra con la autenticación de Azure; scripting más avanzado.

    Azure Cloud Shell

    • Shell Bash o PowerShell en el navegador, sin instalar nada.
    • Trae Azure CLI y Azure PowerShell listos.
    • Puedes asociar almacenamiento para guardar scripts, plantillas y archivos.

    Azure Mobile App

    • Supervisa recursos y recibe alertas.
    • Diagnostica y soluciona problemas rápido.
    • Administra recursos y abre Cloud Shell desde el teléfono.

    Plantillas ARM

    • Azure Resource Manager gestiona y orquesta recursos de forma centralizada.
    • Plantillas declarativas en JSON: describes qué quieres, no los pasos.
    • Despliegues repetibles y controlados; control de acceso basado en roles; etiquetas para organizar.

    Azure Advisor

    • Consultor personalizado: analiza configuración y telemetría de uso.
    • 5 categorías: Costo, Seguridad, Confiabilidad, Excelencia operativa, Rendimiento.
    • Recomienda; no crea ni cambia recursos por sí solo.
