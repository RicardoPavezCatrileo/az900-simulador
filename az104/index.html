AZ-104 · Microsoft Azure Administrator Associate

Simulador AZ-104

Un tema por dominio oficial del examen, construido sobre la base de AZ-900. Cada tema muestra las páginas del PDF del curso AZ-104 y los capítulos de AZ-900 que conviene repasar antes: aquí solo se agrega lo nuevo, el cómo se configura y administra.

Qué cambia respecto de AZ-900

AZ-900 pregunta qué es cada servicio; AZ-104 pregunta cómo se configura: licencias de Entra ID, grupos dinámicos, RBAC por dentro, Bastion, ARM y Bicep, Azure DNS, copias de seguridad. Mismo formato de examen (40–60 preguntas, 120 min, 700/1000), pero la certificación Associate caduca cada año y se renueva gratis en Microsoft Learn (PDF pág. 209).
